# Base de municipios

Coloque aqui a base local de municipios, preferencialmente oficial do IBGE.

Arquivos esperados:

- `municipios_ibge.xlsx`
- `municipios_ibge.csv`

O sistema aceita colunas com nomes flexiveis, como `municipio`, `município`, `nome_municipio`, `uf`, `estado`, `populacao`, `população`, `habitantes`, `capital`, `is_capital`, `site`, `site_oficial` e `url`.

O arquivo `exemplo_municipios.csv` e apenas demonstrativo e nao deve ser usado como resultado final real.
